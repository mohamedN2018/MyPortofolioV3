🧭 الطريقة الأولى: انت بنفسك من اللوحة (من غير Claude)

  1. هات الوظيفة: لقيت وظيفة على LinkedIn أو وظّف أو بيت؟ انسخ رابطها وافتح Job center ← املأ Add a job by link (الرابط، المسمى، الشركة، والوصف لو تحب) ← Save job.
    أو اربط لوحة شركة (Greenhouse / Lever) أو Remote OK من Job accounts واضغط Sync عشان الوظائف تيجي لوحدها.
  2. شوف مدى التوافق: افتح الوظيفة — هتلاقي Match score من 100 وسبب كل جزء (المهارات الناقصة، الخبرة، المكان، الراتب).
  3. جهّز الطلب: اضغط Prepare application — الـ Hub يختار نسخة الـ CV المناسبة (الخليج للسعودية والإمارات، مصر لمصر)، ويكتب خطاب تقديم من بياناتك الموثّقة، ويطلع لك تنبيهات باللي ناقص.
  4. راجع وعدّل: في صفحة الطلب عدّل الخطاب والإجابات براحتك ← Save draft. أي سؤال حساس (الراتب المتوقع، الإقامة، فترة الإشعار) لازم انت اللي تكتب إجابته.
  5. اطلب الموافقة: Request approval to apply ← هتظهر لك معاينة نهائية بكل اللي هيتبعت ← Approve.
  6. قدّم: اضغط Official page ↗ وقدّم على موقع الشركة بنفسك (المواقع دي ما بتسمحش بالتقديم الآلي — وده بيحمي حساباتك من الحظر).
  7. سجّل النتيجة: في صفحة الطلب ← Record outcome ← اختار Submitted واكتب الدليل (رقم الطلب أو إيميل التأكيد) وتاريخ المتابعة.
  8. تابع: Applications فيها لوحة بكل المراحل (مقابلة، عرض، رفض…) وتقدر تصدّرها Excel.

  3. افتح Claude Code وقوله مثلاً:
    «ابحث لي عن وظائف Django في السعودية مناسبة لي، وجهّز أفضل 3 واطلب موافقتي»
  4. Claude هيجيب الوظائف ويحسب التوافق ويجهّز الطلبات ويبعت لك طلبات موافقة — هتلاقيها في Approvals.
  5. توافق ← Claude يفتح لك صفحة التقديم الرسمية ← انت تضغط إرسال ← تقوله "قدّمت، رقم الطلب كذا" وهو يسجّلها.

Claude مش بيقدر يقدّم من غير موافقتك، ومش بياخد أي باسورد، ومش بيقدر يشغّل أوامر على جهازك.

❓ ليه مفيش تقديم أوتوماتيك على LinkedIn؟

LinkedIn وIndeed ووظّف وبيت ما عندهمش طريقة رسمية تسمح لبرنامج يقدّم بدالك، والأتمتة ممنوعة في شروطهم وممكن تقفل حسابك. عشان كده الـ Hub بيعمل كل الشغل التقيل (البحث، التقييم، كتابة الخطاب، الإجابات، المتابعة) ويسيب لك ضغطة الإرسال الأخيرة. شوف جدول قدرات كل موقع.
